Privacy policy

Beelink mail is a personal tool used by one person, its owner, on their own Gmail account. This policy describes how it handles Google user data.

Data it accesses

With the owner's permission through Google sign-in, Beelink mail accesses the owner's Gmail messages: headers (sender, subject, date, labels and Gmail's sender-authentication results) and message text. It also reads which messages the owner has opened, to learn which senders matter.

How the data is used

  • To decide whether each new message stays in the inbox or is archived.
  • To build a daily digest of archived mail, shown only to the owner on a private page.
  • To summarize real-estate listing alert emails for the owner.

The data is used only to provide these features to the owner. It is not sold, not used for advertising, and not shared with anyone else.

Where the data goes

  • The owner's home server. Message metadata, short summaries and the digest are stored on a server in the owner's home, reachable only over the owner's private network. Stored message data is deleted after about four months (the server's encrypted backups keep copies for up to six months longer) and when the tool is uninstalled.
  • Anthropic (Claude). For messages that need judgment, the sender, subject and the first part of the message text are sent to Anthropic's Claude model to classify the message. Only this classification is used. Nothing else is sent to any third party.

No Google user data is used to develop, improve or train generalized artificial intelligence or machine learning models.

Google API Services

Beelink mail's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Your control

The owner can revoke Beelink mail's access at any time at myaccount.google.com/permissions. Revoking access stops all further reading of the account.
